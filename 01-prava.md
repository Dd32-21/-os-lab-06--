Прилагаю скриншот вывода команды для каждого повышения прав 

Заполненная таблица r=4 w=2 x=1 
1 rw-r--r-- = 644
2 rwxr-x--- = 750 
3 rw------- = 600
4 r-xr-xr-x = 555

Файл с правом доступа x дает право запустить этот файл не только читать 
Каталог с x дает право на вход 

chmod -R 777 / дает абсолютно все права т.е любой пользователь способен сломать что то так же будет смесь по правам потому что они все на высшем уровне
